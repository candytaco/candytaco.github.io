rhubarb.portal is a browser-based viewer for Portal 2 co-op demo files. It replays a recorded co-op session directly from the demo file, with no copy of the game required. It is adapted from [dribble.tf](https://dribble.tf), the Team Fortress 2 demo viewer.

rhubarb.portal can be used to visualize the recordings behind the Portal Dialogue Corpus, a collection of spoken dialogue between pairs of players solving cooperative puzzles together, which is described under [Collaborative Cognition](/research/collaborative-cognition/).
