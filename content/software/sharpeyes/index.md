SharpEyes is a package for eyetracking video analysis and correction to generate retinotopic features. It provides a UI for finding pupils in eyetracking videos, the ability to edit the pupil locations manually to ensure data quality, and tools for making retinotopic videos and motion-energy features out of stimulus videos.
